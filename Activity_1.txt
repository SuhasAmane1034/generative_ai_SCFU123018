### 1. Small Model — Phi-3 Mini 4K Instruct

**Creator:** Microsoft
**Parameters:** 3.8 billion
**Generative model:** Yes. It is a decoder-only Transformer that generates text.
**Context length:** 4,096 tokens. ([Hugging Face][1])

**Local execution:** **Yes.** This is the best choice for your 8 GB M2 Mac. Microsoft specifically provides cross-platform support for CPU, GPU and Mac desktops, and the Hugging Face page provides quantized versions. ([Hugging Face][2])

A 4-bit GGUF version is approximately **2.2 GB**, which makes it particularly suitable for your Mac. ([Hugging Face][3])

**Hardware stated in the model card:** Microsoft says the model was trained using **512 H100-80GB GPUs for 10 days**. This is **training hardware**, not the hardware you need to run it locally. ([Hugging Face][1])

**For your lab:**

> Phi-3 Mini is a 3.8B parameter generative language model developed by Microsoft. It has a 4K token context window and is highly suitable for local execution on an M2 Mac with 8 GB RAM, especially using a quantized version.

---

### 2. Medium Model — Mistral 7B Instruct v0.3

**Creator:** Mistral AI
**Parameters:** 7 billion
**Generative model:** Yes. It is an instruction fine-tuned Large Language Model. ([Hugging Face][4])

**Context length:** **32,768 tokens (32K)**. The model configuration specifies `max_position_embeddings: 32768`. ([Hugging Face][5])

**Local execution:** **Yes, but your 8 GB RAM is tight.** The original Hugging Face model is much larger in BF16—the repository is around 29 GB—so for your Mac you should use a **quantized version**, such as 4-bit/GGUF. ([Hugging Face][6])

**Hardware stated by model card:** The Mistral model card gives installation and inference instructions but **does not specify a minimum inference RAM/GPU requirement**. ([Hugging Face][4])

So don't write "Mistral recommends 24 GB RAM" unless your teacher specifically asks for a third-party deployment recommendation.

**For your lab:**

> Mistral 7B Instruct v0.3 is a 7B parameter generative language model developed by Mistral AI. It supports a 32K token context length. It can run locally on an M2 Mac, but an 8 GB machine should use a quantized version to reduce memory requirements.

---

### 3. Large Model — Qwen2.5-14B-Instruct

**Creator:** Qwen / Alibaba Cloud
**Parameters:** **14.7 billion**
**Generative model:** Yes. The model card identifies it as a **Causal Language Model** and its Hugging Face task is text generation. ([Hugging Face][7])

**Context length:** **131,072 tokens (131K)**. It can generate up to 8,192 tokens in a generation. ([Hugging Face][7])

**Local execution on your M2 8 GB:** **No — not practically.**

This is important for your lab. The model has **14.7B parameters**, so even heavily quantized versions require substantially more memory than your Mac has available once macOS and the model's working memory are taken into account.

The Hugging Face card does provide local deployment instructions using Transformers, vLLM, SGLang and Docker, but it does **not** state that an 8 GB Mac is sufficient. ([Hugging Face][7])

**Hardware recommendation:** The model card doesn't give a simple minimum such as "16 GB RAM." It provides deployment methods and recommends using current Transformers versions. Therefore, for your report, say **"High-memory hardware is required; not suitable for an 8 GB M2 Mac."** ([Hugging Face][7])



> Qwen2.5-14B-Instruct is a 14.7B parameter generative language model developed by Qwen/Alibaba Cloud. It supports a 131K token context length. It is a large model and is not practically suitable for local execution on an M2 Mac with only 8 GB RAM.
